# MoneySync — Local-first + Share Link

แอปรายรับ–รายจ่ายส่วนบุคคลที่เก็บข้อมูลหลักใน Local Storage และสร้างลิงก์ Snapshot แบบ read-only ได้

## ไฟล์
- `index.html` — แอปหลัก
- `share.html` — หน้าสำหรับเปิดลิงก์แชร์
- `style.css` — UI
- `app.js` — Local Storage + สร้าง Share Link
- `share.js` — อ่าน Share Link + Import

## วิธีใช้
1. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดเข้า GitHub repository
2. เปิด GitHub Pages
3. เข้าเว็บแล้วเพิ่มรายการได้เลย
4. ข้อมูลหลักจะอยู่ใน Local Storage ของเบราว์เซอร์เครื่องนั้น
5. กด "สร้างลิงก์แชร์" เพื่อสร้าง Snapshot
6. คนที่เปิดลิงก์จะเห็นข้อมูลแบบอ่านอย่างเดียว
7. คนรับสามารถกด "นำข้อมูลเข้าเครื่องนี้" เพื่อคัดลอกข้อมูลเข้า Local Storage ของตัวเอง

## สำคัญเรื่อง Privacy
Share Link รุ่นนี้ "ฝังข้อมูลไว้ใน URL" โดยตรง ไม่ใช้ Database
ดังนั้น:
- ไม่มีข้อมูลหลักถูกส่งไปเก็บบน server
- ใครมีลิงก์สามารถอ่านข้อความที่แชร์ได้
- ลิงก์เก่าไม่เปลี่ยนเมื่อเจ้าของเพิ่ม/ลบข้อมูลภายหลัง
- ถ้าข้อมูลเยอะมาก URL จะยาวขึ้น และอาจเกินข้อจำกัดของบางแอป/เบราว์เซอร์
- อย่าแชร์ข้อมูลลับ เช่น เลขบัญชี รหัสผ่าน หรือข้อมูลการเงินที่ไม่ต้องการให้ผู้ถือ URL เห็น

## GitHub Pages
ไปที่ Settings -> Pages -> Deploy from branch -> เลือก main และ root

## หมายเหตุ
ระบบนี้ไม่มีบัญชีผู้ใช้และไม่มี server database จึงเหมาะกับ personal finance ที่ต้องการ privacy และการแชร์ snapshot มากกว่าการทำบัญชีร่วมแบบ realtime
